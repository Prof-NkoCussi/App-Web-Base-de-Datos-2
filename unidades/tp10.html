32. ORDER BY y LIMIT

Ordenar resultados y mostrar solo una parte

La cláusula ORDER BY se usa para ordenar los resultados de una consulta. La cláusula LIMIT se usa para restringir el número de filas que se devuelven en el resultado.

¿Para qué sirven?

  • Ordenar de menor a mayor

    Permite mostrar los registros en orden ascendente.

  • Ordenar de mayor a menor

    Permite mostrar los registros en orden descendente.

  • Mostrar primeros registros

    Permite mostrar solo algunas filas del resultado.

  • Preparar listados y reportes

    Ayuda a obtener información más útil y organizada para un análisis.

Sintaxis básica

  • Ordenar de menor a mayor (ASC)

    1. SELECT * FROM productos
    2. ORDER BY precio ASC;

  • Ordenar de mayor a menor y limitar resultados

    1. SELECT * FROM productos
    2. ORDER BY precio DESC LIMIT 3;

Ejemplo en una tabla

PRODUCTOS
id_productonombreprecio

3Monitor12000

Consulta y resultado

Consulta

El resultado muestra solo los 3 productos con mayor precio, ordenados de forma descendente.

Puntos importantes

  • ASC

    Ordena los resultados de menor a mayor. Es el orden por defecto.

  • DESC

    Ordena los resultados de mayor a menor.

  • LIMIT

    Permite mostrar solo un número específico de filas.

  • Combinación con WHERE

    Puedes usar ORDER BY y LIMIT junto con WHERE para filtrar, ordenar y limitar resultados.

Idea clave: La cláusula ORDER BY organiza el resultado de una consulta y la cláusula LIMIT controla cuántas filas se muestran.

33. UPDATE y DELETE

Modificar y eliminar registros

El comando UPDATE permite modificar registros existentes en una tabla. El comando DELETE se usa para eliminar registros de una tabla.

¿Qué hace cada uno?

  • UPDATE

    Modifica el valor de una o más columnas en los registros que cumplen una condición.

  • DELETE

    Elimina registros completos de una tabla que cumplen una condición.

Sintaxis

  • UPDATE

    1. UPDATE clientes
    2. SET ciudad = 'Ushuaia'
    3. WHERE id_cliente = 2;

  • DELETE

    1. DELETE FROM productos
    2. WHERE stock = 0;

Ejemplo en una tabla

Cuidados importantes

  • Usar WHERE

    Siempre usa una condición para evitar cambios no deseados.

  • Revisar antes de ejecutar

    Verifica que la condición sea correcta.

  • UPDATE modifica

    Solo cambia los valores de los registros existentes. No elimina registros.

  • DELETE elimina

    Borra completamente los registros que cumplen la condición.

Idea clave: Los comandos UPDATE y DELETE permiten modificar los datos almacenados en una tabla. La cláusula WHERE ayuda a evitar cambios no deseados.

34. QBE: consultas por ejemplo

Armar una consulta sin escribir SQL

QBE (Query By Example, consulta por ejemplo) es una forma de armar consultas sin escribir SQL: se completa una grilla con la tabla, los campos, el orden y las condiciones, y el programa arma la consulta. Lo creó Moshé Zloof en IBM, en los años 70.

Pestaña Buscar

De una tabla, con un formulario.

  1. Elegí la tabla a la izquierda y entrá a la pestaña Buscar.
  2. En cada columna, elegí el Operador y escribí el Valor: en precio, > y 10000.
  3. Para ordenar, abrí Opciones extra y elegí la columna en Ordenar por, con Ascendente o Descendente.
  4. Hacé clic en Continuar: arriba del resultado aparece el SQL que armó.

Pestaña Generar una consulta

De la base: una o varias tablas, con orden y criterios.

  1. Elegí la base a la izquierda, entrá a Generar una consulta y después a Consulta por ejemplo.
  2. En cada Columna de la grilla, elegí un campo y marcá Mostrar si va en el resultado.
  3. Completá Ordenar y Criterio, y hacé clic en Actualizar la consulta: abajo aparece el SQL.
  4. Con Ejecutar la consulta, se ve el resultado.

Ejemplo: grilla QBE y SQL

Los productos con precio mayor a 10000, de mayor a menor.

Grilla QBE
Columna`productos`.`nombre``productos`.`precio`
Mostrar
Ordenar(vacío)Descendente

SQL
  1. SELECT nombre, precioColumna y Mostrar

Cada fila de la grilla es una parte de la consulta, y phpMyAdmin siempre muestra el SQL que genera. QBE y SQL hacen lo mismo: la grilla es otra forma de escribir la consulta.

Idea clave: Con QBE se arma una consulta completando una grilla, sin escribir SQL. El programa la traduce a SQL: las dos formas hacen lo mismo.

+ Para profundizar

Un poco más sobre cada lámina

Lámina 32

Desempates y páginas

Con dos columnas, ORDER BY ordena por la primera y, si dos filas empatan, por la segunda. En la tienda, ordena por ciudad y, dentro de cada una, por nombre: en Ushuaia, Ana, Martín y Pedro.

  1. SELECT ciudad, nombre FROM clientes
  2. ORDER BY ciudad, nombre;

OFFSET dice desde dónde empezar: LIMIT 3 OFFSET 3 saltea 3 filas y muestra las 3 siguientes (por precio: Auriculares, Mouse y Teclado).

Resultados por páginas

Un listado largo, de a 3 por página:

  • Página 1: LIMIT 3
  • Página 2: LIMIT 3 OFFSET 3
  • Página 3: LIMIT 3 OFFSET 6

Sin ORDER BY, el orden no está asegurado: para mostrar por páginas, hay que ordenar.

Lámina 33

Antes de cambiar, mirar

Sin WHERE, UPDATE cambia todas las filas y DELETE las borra todas: UPDATE productos SET stock = 0; deja sin stock a los 8 productos de la tienda.

La costumbre segura: probar antes el mismo WHERE con un SELECT y, si trae las filas que se quería cambiar, ejecutar el UPDATE o el DELETE.

  1. SELECT * FROM productos WHERE stock < 5;
  2. DELETE FROM productos WHERE stock < 5;

Cuando DELETE no puede borrar

Si otra tabla tiene una clave foránea que apunta a esa fila, el gestor no deja borrarla y da un error: es la integridad referencial (TP4, lámina 12). En la tienda, no se puede borrar a Ana (id_cliente = 1) porque tiene ventas.

Lámina 34

QBE en otros programas

La idea de Zloof sigue en muchos programas. En Access y en LibreOffice Base, la vista Diseño de una consulta es una grilla QBE: una columna por campo y filas para la tabla, el orden, si se muestra y el criterio. Los dos permiten ver también la consulta en SQL.

¿QBE o SQL?

  • QBE conviene para consultas cortas, para explorar una tabla o para ver cómo se escribe algo en SQL.
  • SQL conviene para consultas largas, para guardarlas y volver a usarlas, y para lo que la grilla no tiene: en phpMyAdmin, la grilla arma solo consultas SELECT.

Todo junto

Los 3 más jóvenes de Ushuaia

  1. SELECT nombre, edad FROM clientes
  2. WHERE ciudad = 'Ushuaia'
  3. ORDER BY edad LIMIT 3;
  1. WHERE: quedan Ana (28), Pedro (40) y Martín (19).
  2. ORDER BY edad: Martín, Ana y Pedro.
  3. LIMIT 3: salen los 3. LIMIT es un tope: si hay menos filas, muestra las que hay.

El orden de las cláusulas

Siempre SELECT, FROM, WHERE, ORDER BY y LIMIT. Si LIMIT va antes de ORDER BY, da error.
