19. Álgebra relacional

Las operaciones detrás de cada consulta

El álgebra relacional es un conjunto de operaciones sobre tablas: cada una toma una o dos tablas y devuelve otra tabla. Es la base de los lenguajes de consulta, como SQL.

Cuatro operaciones

Los ejemplos usan las tablas del TP2 (lámina 6).

  • σ

    Selección

    En SQL: WHERE

    Elige las filas que cumplen una condición.

    σ creditos > 2 (CURSOS) devuelve las filas de Matemática y de Historia.

    1. SELECT * FROM cursos
    2. WHERE creditos > 2;
  • π

    Proyección

    En SQL: SELECT columnas

    Elige las columnas que se quieren ver.

    π nombre (ALUMNOS) devuelve solo la columna nombre: Ana, Luis y Marta.

    1. SELECT nombre FROM alumnos;
  • ×

    Producto cartesiano

    En SQL: FROM a, b

    Combina cada fila de una tabla con cada fila de otra.

    ALUMNOS × CURSOS devuelve 3 × 3 = 9 filas: cada alumno con cada curso.

    1. SELECT * FROM alumnos, cursos;

  • Reunión

    En SQL: JOIN (TP11)

    Combina las filas que coinciden en un campo.

    ALUMNOS INSCRIPCIONES devuelve 3 filas, unidas por id_alumno: Ana con 101, Luis con 102 y Ana con 102.

    Es un × seguido de una σ: de las 9 combinaciones quedan las 3 en las que coincide id_alumno.

Operaciones encadenadas

Cada operación devuelve una tabla, que puede entrar en otra.

π nombre (σ id_alumno = 1 (ALUMNOS))

SQL
  1. SELECT nombre
  2. FROM alumnos
  3. WHERE id_alumno = 1;

Resultado: Ana.

Se lee de adentro hacia afuera, como trabaja el gestor.

  1. FROM alumnos: la tabla ALUMNOS.
  2. WHERE id_alumno = 1 es σ id_alumno = 1: queda la fila de Ana.
  3. SELECT nombre es π nombre: queda la columna nombre.

Idea clave: SQL dice qué datos se quieren; el álgebra relacional muestra las operaciones que hace el gestor para obtenerlos.

20. ¿Qué es SQL y para qué sirve?

El lenguaje para trabajar con bases de datos

SQL significa Structured Query Language. Es el lenguaje que usamos para crear, consultar, modificar y organizar la información dentro de una base de datos relacional.

¿Para qué sirve?

  • Consultar datos

    Permite buscar y obtener información.

  • Agregar información

    Permite insertar nuevos registros.

  • Modificar registros

    Permite actualizar datos existentes.

  • Eliminar datos

    Permite borrar registros.

Ejemplos simples

  • Consultar datos

    SQL
    1. SELECT * FROM clientes;

  • Agregar información

    SQL
    1. INSERT INTO productos
    2. (nombre, precio)
    3. VALUES ('Mouse', 25000);

  • Modificar registros

    SQL
    1. UPDATE clientes
    2. SET ciudad = 'Córdoba'
    3. WHERE id_cliente = 1;

¿Dónde se usa?

  • Escuelas

    Para gestionar alumnos y cursos.

  • Comercios

    Para administrar productos y ventas.

  • Bancos

    Para manejar cuentas y clientes.

  • Aplicaciones

    Para almacenar y gestionar datos.

Idea clave: SQL no guarda los datos por sí solo: permite comunicarnos con la base de datos para administrarla.

21. Puesta en marcha de XAMPP

Del panel de control a phpMyAdmin Repaso de 5.º

XAMPP instala en la computadora un servidor de bases de datos y phpMyAdmin, una página para manejarlo desde el navegador. Con él se hacen todas las actividades en la computadora de este año.

El módulo que XAMPP llama “MySQL” en realidad es MariaDB, un gestor hecho a partir de MySQL que se usa igual.

Paso a paso

  1. Abrí el panel de control de XAMPP desde el menú Inicio: XAMPP Control Panel.
  2. Hacé clic en Start en las filas de Apache y de MySQL. Cuando arrancan, el nombre se pone en verde y el botón dice Stop.
  3. En el navegador, entrá a localhost/phpmyadmin (o hacé clic en Admin, en la fila de MySQL).
  4. Para crear una base: Nueva, a la izquierda; escribí el nombre y hacé clic en Crear. Para cargar un archivo .sql: pestaña Importar, elegí el archivo y hacé clic en Importar.
  5. Para escribir instrucciones: elegí la base a la izquierda, pestaña SQL. Escribí la instrucción y hacé clic en Continuar: el resultado aparece debajo.

Si no arranca

Si Apache o MySQL no se ponen en verde, casi siempre es porque otro programa ya usa su puerto: el 80 (Apache) o el 3306 (MySQL). El panel lo avisa en los mensajes de abajo.

Cerrá ese programa o cambiá el puerto en la configuración de XAMPP (se ve en el TP13).

Idea clave: Con Apache y MySQL en verde se entra a phpMyAdmin, donde se crean las bases y se ejecuta el SQL.

22. Familias de comandos SQL: DDL, DML, DQL y TCL

Cuatro grupos para entender qué hace cada instrucción

Los comandos SQL suelen agruparse en familias según su función. Esto ayuda a entender para qué sirve cada instrucción.

  • DDLdefine la estructura

    Se usa para crear, modificar o eliminar objetos de la base de datos (tablas, vistas, etc.).

    Ejemplos: CREATE, ALTER, DROP

  • DMLmanipula datos

    Se usa para insertar, actualizar o eliminar registros de las tablas.

    Ejemplos: INSERT, UPDATE, DELETE

  • DQLconsulta información

    Se usa para consultar y recuperar datos de la base de datos.

    Ejemplos: SELECT

  • TCLcontrola transacciones

    Se usa para gestionar transacciones y asegurar la integridad de los datos.

    Ejemplos: COMMIT, ROLLBACK

Comparativa de las familias de comandos SQL

DMLManipula los datos de las tablas.INSERT, UPDATE, DELETE

Ejemplo rápido

  • DDL – Crear una tabla

    SQL
    1. CREATE TABLE clientes (
    2. id_cliente INT,
    3. nombre VARCHAR(100)
    4. );

  • DML – Insertar un registro

    SQL
    1. INSERT INTO clientes
    2. (id_cliente, nombre)
    3. VALUES (1, 'Ana');

  • DQL – Consultar datos

    SQL
    1. SELECT *
    2. FROM clientes;

  • TCL – Confirmar cambios

    SQL
    1. COMMIT;

Idea clave: Si sabes qué familia usa cada comando, entiendes mejor el papel de cada instrucción dentro de SQL.

Lámina 19

Unión, diferencia e intersección

Otras tres operaciones, para dos tablas con las mismas columnas:

  • Unión (): las filas de las dos, sin repetir.
  • Diferencia (−): las de la primera que no están en la otra.
  • Intersección (): las que están en las dos.

Ejemplo: alumnos de dos cursos

A, los de Matemática: Ana, Bruno y Carla. B, los de Historia: Bruno, Carla y Diego.

Lámina 21

Qué hay dentro de XAMPP

  • Apache: el servidor web; entrega las páginas.
  • MariaDB: el gestor; guarda los datos y ejecuta el SQL.
  • PHP: el lenguaje en el que está hecho phpMyAdmin.
  • phpMyAdmin: una página para manejar MariaDB.

Qué es localhost

localhost es el nombre con el que la computadora se llama a sí misma: el pedido a localhost/phpmyadmin no sale a internet.

Tu computadora (localhost)

  1. Navegador
  2. Apache + PHPphpMyAdmin · puerto 80
  3. MariaDBpuerto 3306

Lámina 22

La quinta familia: DCL

DCL (control de datos) maneja los permisos de los usuarios: GRANT los da y REVOKE los quita. Se ve en el TP13.

En muchos libros, DQL va dentro de DML: SELECT también trabaja con los datos.

Ejemplo: los permisos de un preceptor

SQL
  1. GRANT SELECT ON escuela.*
  2. TO 'preceptor'@'localhost';
  3. REVOKE SELECT ON escuela.*
  4. FROM 'preceptor'@'localhost';

GRANT deja que el usuario preceptor consulte las tablas de escuela; REVOKE le quita ese permiso.
