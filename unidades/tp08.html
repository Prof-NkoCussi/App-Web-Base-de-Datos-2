26. SELECT – consultar información

Obtener datos desde una tabla Repaso de 5.º

SELECT se usa para consultar y recuperar la información almacenada en una tabla. Permite ver los registros que cumplen con lo que necesitamos.

¿Para qué sirve?

  • Ver registros

    Permite consultar y mostrar los registros de una tabla.

  • Elegir columnas

    Permite seleccionar solo las columnas que necesitamos.

  • Ordenar resultados

    Permite mostrar los datos en un orden específico.

  • Analizar información

    Facilita revisar, comparar y analizar los datos.

Sintaxis básica

SQL
  1. SELECT * FROM clientes;

Ejemplo en una tabla

CLIENTES
id_clientenombreemailciudad
1Anaana@mail.comUshuaia
2Carloscarlos@mail.comTolhuin
3Lauralaura@mail.comRío Grande
4Pedropedro@mail.comBuenos Aires

Consulta y resultado

Consulta SQL
  1. SELECT * FROM clientes;
Resultado
id_clientenombreemailciudad
1Anaana@mail.comUshuaia
2Carloscarlos@mail.comTolhuin
3Lauralaura@mail.comRío Grande
4Pedropedro@mail.comBuenos Aires

Puntos importantes

  • No modifica datos

    SELECT solo lee información, no cambia los datos de la tabla.

  • Devuelve resultados

    Muestra un conjunto de registros que coinciden con la consulta.

  • Se usa con otras cláusulas

    Puede combinarse con WHERE, ORDER BY, etc. para filtrar u ordenar.

  • Puede consultar una o varias tablas

    Se puede usar en una tabla o en varias tablas relacionadas.

Idea clave: SELECT nos permite obtener los datos que necesitamos desde una o varias tablas sin modificar la información.

27. SELECT de columnas específicas + alias

Elegir solo la información necesaria

El comando SELECT permite obtener solo algunas columnas de una tabla. Los alias se usan para renombrar las columnas en el resultado y mostrar nombres más amigables.

¿Qué cambia?

  • Menos información

    Se muestran solo las columnas que necesitas.

  • Más claridad

    Los resultados son más fáciles de leer y entender.

  • Resultados personalizados

    Puedes elegir las columnas que te interesan.

  • Nombres más amigables

    Los alias permiten mostrar nombres más claros en el resultado.

Sintaxis

SQL
  1. -- Seleccionar columnas específicas
  2. SELECT nombre, email FROM clientes;
  3. -- Usar alias para renombrar columnas
  4. SELECT nombre AS cliente, ciudad AS localidad
  5. FROM clientes;

¿Qué es un alias?

Un alias es un nombre temporal que se asigna a una columna en el resultado de una consulta. Se usa la palabra clave AS.

  1. SELECT nombre AS cliente FROM clientes;

Ejemplo en una tabla

CLIENTES
clientelocalidad
AnaUshuaia
CarlosTolhuin
LauraRío Grande
PedroBuenos Aires

Este resultado se obtiene con:

  1. SELECT nombre AS cliente,
  2. ciudad AS localidad
  3. FROM clientes;

Puntos importantes

  • No cambia el nombre real de la columna.

    El alias solo se usa en el resultado.

  • Mejora la lectura de los resultados.

    Permite mostrar nombres más claros.

  • Sirve en reportes.

    Es útil para generar listados e informes más entendibles.

  • Puede usarse en resultados.

    El alias se muestra solo en el resultado de la consulta.

Idea clave: Con SELECT eliges solo las columnas que necesitas, y con AS puedes darles un nombre más amigable en el resultado.

28. WHERE – filtrar registros

Mostrar solo los datos que cumplen una condición

La cláusula WHERE se usa para filtrar los registros de una tabla. Permite mostrar solo las filas que cumplen una condición específica.

¿Para qué sirve?

  • Buscar un dato

    Permite encontrar registros específicos.

  • Limitar resultados

    Muestra solo la información necesaria.

  • Encontrar coincidencias

    Filtra filas que cumplen una condición.

  • Preparar reportes

    Ayuda a obtener datos más relevantes para un análisis.

Sintaxis básica

SQL
  1. SELECT * FROM clientes
  2. WHERE ciudad = 'Ushuaia';

Ejemplo en una tabla

CLIENTES
id_clientenombreciudadedad
1AnaUshuaia28
2CarlosTolhuin35
3LauraRío Grande22
4PedroUshuaia40

Consulta y resultado

Consulta
  1. SELECT * FROM clientes
  2. WHERE ciudad = 'Ushuaia';
Resultado (solo filas que cumplen la condición)
id_clientenombreciudadedad
1AnaUshuaia28
4PedroUshuaia40

Condiciones comunes

  • =

    Igual a un valor.

    ciudad = 'Ushuaia'

  • >

    Mayor que un valor.

    edad > 30

  • <

    Menor que un valor.

    precio < 10000

  • <>

    Distinto de un valor.

    ciudad <> 'Tolhuin'

La cláusula WHERE se usa antes de ORDER BY en una consulta SQL.

Idea clave: WHERE permite filtrar los registros de una tabla y mostrar solo los datos que cumplen una condición.

+ Para profundizar

Un poco más sobre cada lámina

Lámina 26

En qué orden se lee una consulta

Se escribe SELECT, FROM, WHERE, pero el gestor la resuelve en otro orden:

  1. FROM clientes: busca la tabla.
  2. WHERE edad > 30: elige las filas.
  3. SELECT nombre: elige las columnas.

Por eso, el WHERE no reconoce un alias del SELECT (lámina 27): cuando filtra, el alias todavía no existe.

¿Asterisco o columnas?

Para mirar una tabla, SELECT * alcanza. En un programa que consulta la base (TP12) conviene nombrar las columnas: trae solo lo que usa y, si a la tabla se le suma una columna (TP7), devuelve lo mismo.

Lámina 27

Cuentas, alias y DISTINCT

Una columna del resultado puede ser una cuenta, que el gestor hace en cada fila; la tabla no cambia.

  1. SELECT nombre,
  2. precio * 1.21 AS precio_con_iva
  3. FROM productos;

El Teclado (40000) da 48400.0000: dos decimales del precio y dos de 1.21.

Si el alias tiene espacios, va entre comillas dobles: AS "Precio con IVA".

Sin repetir: DISTINCT

SELECT DISTINCT ciudad FROM clientes; muestra cada ciudad una vez: con la tabla de la lámina 28, Ushuaia, Tolhuin y Río Grande.

Lámina 28

Comillas y valores vacíos

Los textos van entre comillas simples; los números, sin comillas: ciudad = 'Ushuaia', edad > 30. Sin las comillas, el gestor toma Ushuaia como el nombre de una columna y da error.

Valores vacíos: NULL

Una celda sin dato queda en NULL, que no es un valor sino la falta de uno: no se busca con =, sino con IS NULL.

Qué devuelve cada condición para buscar los clientes con o sin email
CondiciónDevuelve
email IS NULLLos clientes sin email
email IS NOT NULLLos que tienen email
email = NULLNinguna fila, y no da error

Todo junto

Del álgebra a SQL

Las columnas del SELECT son la proyección (π) del TP6, y el WHERE, la selección (σ).

π nombre, edad (σ ciudad = 'Ushuaia' (CLIENTES))

Cada parte de la consulta SQL y su parte en la expresión de álgebra
En SQLEn álgebra
SELECT nombre, edadπ nombre, edad
FROM clientesCLIENTES
WHERE ciudad = 'Ushuaia'σ ciudad = 'Ushuaia'

Con la tabla de la lámina 28 da Ana, 28 y Pedro, 40. Se lee de adentro hacia afuera.

Ojo con los nombres

La selección (σ) es el WHERE, no el SELECT. Con SELECT * no hay π: van todas las columnas.
